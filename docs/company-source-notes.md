# 회사별 공시 URL 점검 메모

점검 기준일: 2026-11-06

- 삼성화재: 전달받은 URL이 정기경영공시 페이지다. 공개된 페이지 텍스트에 FY 26의 1분기와 2분기 PDF 다운로드 항목이 노출된다. 사이트가 PDF를 직접 href로 제공하는지 JavaScript 다운로드로 제공하는지는 실행 시 브라우저 어댑터가 확인한다.
- KB손해보험: 전달받은 URL이 정기공시 페이지다. 공개된 목록에서 FY 2026의 `-2/4분기 경영통일공시`가 2026-08-31 등록으로 표시되고, 1/4분기도 2026-05-29 등록으로 표시된다. 표 행 내부 링크/클릭 동작을 수집 대상으로 삼는다.
- 메리츠화재: 전달받은 URL은 `periodic.do#!/` 형태의 JavaScript 페이지다. 정적 텍스트 추출만으로 첨부 링크를 확정하지 못해 Playwright로 렌더링 후 목록/다운로드 요소를 확인하도록 구성했다. 그룹 사이트의 자료와 메리츠화재 자체 자료를 혼동하지 않도록 전달받은 메리츠화재 URL을 우선 사용한다.
- 현대해상: 전달받은 공통 `serviceAction.do` 진입점에서 공시실 메뉴를 확인했다. 정기경영공시 목록을 직접 가리키는 검색 확인 주소는 `https://www.hi.co.kr/serviceAction.do?menuId=100999`로 정리해 사용한다. 해당 목록은 JavaScript 템플릿 기반이며 `fnGoDetailView(...)` 클릭으로 상세 화면에 진입하는 구조가 페이지 텍스트에 노출된다.

공개 웹 페이지의 정적 파싱과 GitHub Actions의 실제 로그인 없는 브라우저 수집은 실행 환경 차이가 있을 수 있다. 각 회사별 최초 수집 후 `data/exports/collection_status.csv` 및 로그에서 결과를 검증해야 한다.
