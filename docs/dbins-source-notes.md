# DB손해보험 사이트 구조 점검 메모

점검일: 2026-11-06

## 목록 페이지

<https://www.idbins.com/pc/bizxpress/contentTemplet/pb/mp/rg/list.jsp>

`경영공시 및 공고 → 정기경영공시`에 등록번호, 제목, 파일, 등록일 목록이 표시됩니다. 제목을 누르면 게시물 상세 페이지로 이동하고, 상세 페이지의 `파일` 영역에서 PDF 첨부 링크를 얻을 수 있습니다.

## 확인한 최신 게시물 예시

| 게시물 | 등록일 | 상세 페이지 |
|---|---:|---|
| 2026년 상반기 DB손해보험 현황(경영공시) | 2026-08-31 | `view.jsp?ct=1&i=ce54841ddf06476cbfd4&tp=T&tx=` |
| 2026년 1분기 DB손해보험 현황(경영공시) | 2026-05-29 | `view.jsp?ct=2&i=4c3187cc8627450a93bc&tp=T&tx=` |

두 게시물 모두 PDF 첨부가 3개입니다.

- 상반기: `2026083101.pdf`, `2026083102.pdf`, `2026083103.pdf`
- 1분기: `2026052901.pdf`, `2026052902.pdf`, `2026052903.pdf`

PDF URL 형태는 다음과 같습니다.

```text
https://www.idbins.com/pcweb/bizxpress/pb/mp/rg/__etc/{파일명}
```
